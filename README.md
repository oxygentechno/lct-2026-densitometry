# DXA quality pipeline

Захардкоженый spacing: 0.6 мм по X, 1.05 мм по Y. Сторона бедра в `anatomical_region` не пишется.

`quality_class` — правила (1, если есть хотя бы одна причина). `quality_prob` — отдельный классификатор, в вердикт не входит.

## Запуск

Python 3.11, пакеты из `requirements.txt`. `torch`/`torchvision` ставятся с `https://download.pytorch.org/whl/cu128` (CUDA 12.8).

```bash
pip install -r requirements.txt
```

Для инференса чекпоинты нужно положить в `weights/` с именами `{experiment}_{checkpoint}.ckpt`, как в `config.py`.

```python
from pipeline import DXAPipeline

pipe = DXAPipeline()
frame, results = pipe.run_batch(["a.dcm", "b.dcm"])
image = pipe.draw_visualization(results[0])

frame.to_csv("results.csv", index=False)
frame.to_excel("results.xlsx", index=False)
```

## Поля ответа

Одна строка — один кадр, колонки в этом порядке.

| поле | смысл |
|---|---|
| `path_to_study` | путь к DICOM |
| `study_uid` | `StudyInstanceUID` |
| `image_uid` | `SOPInstanceUID` |
| `anatomical_region` | `Поясничный отдел позвоночника` или `Проксимальный отдел бедра` |
| `quality_class` | `0` годен, `1` брак |
| `violation_type` | закрытый список; пусто если годен; несколько через `"; "` |
| `processing_status` | `Success` / `Failure` |
| `time_of_processing` | секунды |
| `quality_prob` | вероятность брака `[0, 1]` |

Позвоночник: `Некорректная укладка`; `Не выравнена ось позвоночника`; `Присутствуют посторонние предметы`.  
Бедро: `Некорректная укладка`; `Некорректная область интереса`.

## Правила

**Позвоночник.** Нет Th12–L5 или подвздошных, Th12 < 50% высоты L1–L4, столб дальше 15 мм от центра кадра → укладка. Угол L1–L5 > 5° → ось. Маска металла → посторонние предметы.

**Бедро.** Нет большого вертела, шейки или седалищной; нет малого вертела; выступ МВ > 10 мм; ось диафиза > 5° → укладка. Запас поля < 3 см вверх от большого вертела / вниз от седалищной или < 2 см латерально; протез → область интереса.

## Визуализация

Публичная (`draw_visualization`) — измерения и сайдбар. Приватная (`draw_private_visualization`) — плюс маски и точки.

На снимке позвоночника: артефакт, хорда L1–L5, вертикаль, градусы. На снимке бедра: протез, три луча в см, выступ МВ в мм, ось диафиза.

Сайдбар. Заключение: годен / брак. Правильная укладка / правильный ROI: `да` = норма. Смещение оси / посторонние предметы: `да` = нарушение. Кружок зелёный при норме, красный при браке; `н/д` — без кружка.
